## 💻 วิธีการทำงานสำหรับผู้รับผิดชอบฟีเจอร์นี้:
1. สลับ Git Branch ไปที่งานของคุณ:
   ```bash
   git checkout feature/frontend-setup
   ```
2. พัฒนาและแก้ไขโค้ดในไฟล์ที่เกี่ยวข้อง
3. บันทึกและ Push งาน:
   ```bash
   git add .
   git commit -m "feat: update Frontend: Project Setup & Layout"
   git push origin feature/frontend-setup
   ```
