## 💻 วิธีการทำงานสำหรับผู้รับผิดชอบฟีเจอร์นี้:
1. สลับ Git Branch ไปที่งานของคุณ:
   ```bash
   git checkout feature/backend-core-db
   ```
2. พัฒนาและแก้ไขโค้ดในไฟล์ที่เกี่ยวข้อง
3. บันทึกและ Push งาน:
   ```bash
   git add .
   git commit -m "feat: update Backend: Core & Database"
   git push origin feature/backend-core-db
   ```
