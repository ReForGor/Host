## 💻 วิธีการทำงานสำหรับผู้รับผิดชอบฟีเจอร์นี้:
1. สลับ Git Branch ไปที่งานของคุณ:
   ```bash
   git checkout feature/backend-admin
   ```
2. พัฒนาและแก้ไขโค้ดในไฟล์ที่เกี่ยวข้อง
3. บันทึกและ Push งาน:
   ```bash
   git add .
   git commit -m "feat: update Backend: Admin & Telemetry"
   git push origin feature/backend-admin
   ```
