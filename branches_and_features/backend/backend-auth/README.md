# 📁 Backend: Authentication
* **Git Branch ที่ต้องใช้:** `feature/backend-auth`
* **หน้าที่ความรับผิดชอบ:** ทำระบบ Login / JWT Token / สิทธิ์ผู้ใช้งาน
* **ไฟล์โค้ดหลักในโปรเจกต์:** `backend/features/auth/router.py, backend/core/security.py`

---

## 💻 วิธีการทำงานสำหรับผู้รับผิดชอบฟีเจอร์นี้:
1. สลับ Git Branch ไปที่งานของคุณ:
   ```bash
   git checkout feature/backend-auth
   ```
2. พัฒนาและแก้ไขโค้ดในไฟล์ที่เกี่ยวข้อง
3. บันทึกและ Push งาน:
   ```bash
   git add .
   git commit -m "feat: update Backend: Authentication"
   git push origin feature/backend-auth
   ```
